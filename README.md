# Pharmacy Inventory Laravel

## Overview
A pharmacy inventory management system built with Laravel.  
Features include:
- FIFO Sales with batch preview
- Stock management and expiry alerts
- Reports for sales, stock, and expiry

## Installation
1. Clone the repository
2. Run `composer install`
3. Configure `.env` file
4. Run migrations: `php artisan migrate`
5. Start server: `php artisan serve`
